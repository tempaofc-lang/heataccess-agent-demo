# HeatAccess public demonstration

Live site: https://tempaofc-lang.github.io/heataccess-agent-demo/

This browser-only site shows a snapshot of the South Bronx park walkability research prototype. It includes an interactive map, 33 precomputed walking scenarios, a rules-based question interface, a per-park OSM entrance-tag desk audit, and scenario-specific HTML reports. It does not use a live language model or backend.

The entrance-tag audit is not field verification. Public access and opening hours are unconfirmed. The original coverage estimate still uses network proxies; four parks with no network proxy have nearby OSM gate candidates. See the audit page and data license before interpreting the estimates. Official cross-checks include the [NYC Parks Colgate Close page](https://nycgovparks.org/parks/x195a/map), [Fort Tryon Park map](https://www.nycgovparks.org/parks/M029/map/ft_tryon_map.pdf), and [NYC DOT Bronx River Greenway route into Garrison Park](https://www.nyc.gov/html/dot/downloads/pdf/bronx-river-greenway-bike-tour.pdf). These sources do not verify that every candidate gate is open today.

Source project: https://github.com/tempaofc-lang/heataccess-agent (private). Data sources and license details: [data/DATA_LICENSE.md](data/DATA_LICENSE.md).
